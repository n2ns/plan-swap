# PlanSwap 使用指南

[English](user-guide.md) · [简体中文](user-guide.zh-cn.md) · **繁體中文** · [Español](user-guide.es.md) · [日本語](user-guide.ja.md)

PlanSwap 讓你同時保持多個 Claude Code 和 Codex 帳號的登入狀態，並選擇編輯器要使用哪一個。本指南介紹側邊欄的各項控制項、帳號設定、切換、用量額度和日常維護。Claude 和 Codex 彼此獨立管理：切換其中一個不會切換另一個。

下文的按鈕名稱採用繁體中文介面的文字。將滑鼠游標停留在圖示上可以看到它的名稱。面板底部頁尾中的書本圖示可開啟本指南。

## 開始之前

你需要：

- 相容 VS Code 1.107 以上版本的編輯器（VS Code、Antigravity IDE 或 VSCodium）。PlanSwap 可在 WSL 遠端視窗、原生 Windows、本機 Linux 桌面或其他遠端視窗中執行。不支援 macOS。
- 在該視窗執行的環境中安裝 PlanSwap，以及官方 Claude Code 和/或 Codex 擴充功能。
- 該環境的 PATH 中有 `claude` 命令，用於在終端機登入和查詢 Claude 用量額度；有 `codex` 命令，用於在終端機登入 Codex。安裝了 Codex 擴充功能時，即使沒有該命令也能查詢 Codex 用量額度。
- 在原生 Windows 以外的環境中切換 Codex：登入 shell 必須是 Bash。

安裝步驟以及各編輯器的測試程度，請參閱[安裝說明](../README.md#install)和[支援的編輯器](../README.md#supported-editors)。

## 熟悉側邊欄

在活動列中按一下 **PlanSwap**，然後選擇 **Claude** 或 **Codex** 索引標籤。

- **預設帳號**：你現有的設定，通常是 `~/.claude` 或 `~/.codex`。在 Windows 上，`~` 指你的 Windows 使用者設定檔資料夾；在 WSL 中，指該發行版本內的主目錄。如果編輯器已經設定了 `CLAUDE_CONFIG_DIR`，Claude 的預設目錄會隨之改變。
- **具名帳號**：像 `work` 或 `personal` 這樣的帳號，每個都有自己的目錄，例如 `~/.claude-work` 或 `~/.codex-work`。
- **外部目錄**：編輯器目前正在使用、但不在 PlanSwap 帳號清單中的目錄。它無法在 PlanSwap 中重新命名或移除。
- **醒目提示的第一列**：目前帳號。對 Codex 而言，這是本視窗中生效的帳號，可能與你已選擇、正在等待重新啟動的帳號不同。
- **連結標記**：表示已連結帳號，它使用預設帳號的設定、規則、技能、記錄和工作階段，登入則保持獨立。

本指南中的用語：

- 「登入」即 **登入** 按鈕；未登入的列顯示 **未登入**。
- 「連結」是介面中帶有連結標記的模式。**與預設帳號共用** 命令可把獨立帳號改為已連結帳號。
- 對 Codex 而言，「生效帳號」是本視窗目前使用的帳號；「已選擇帳號」是下次重新啟動後將使用的帳號。

每張卡片會顯示帳號的顯示名稱和登入狀態，取得之後還會顯示電子郵件、方案和用量額度。將滑鼠游標停留在卡片上可查看它的目錄。

重新整理按鈕有兩種：

- 面板標題列中的重新整理按鈕會重新掃描兩份帳號清單，並重新載入登入資訊。
- **全部帳號** 旁邊的圖示用於查詢用量額度。請參閱[查看和重新整理用量額度](#查看和重新整理用量額度)。

面板底部的頁尾在兩個索引標籤上都會一直顯示。其中的按鈕分別用於顯示版本、開啟本指南、重新載入視窗、重新啟動擴充功能主機和開啟 GitHub 存放庫。按鈕下方會顯示已安裝的 PlanSwap 版本。

## 新增並登入帳號

對於 Codex，請先[啟用切換](#啟用並切換-codex-帳號)。

1. 在對應的索引標籤中，按一下 **全部帳號** 旁邊的 **+ 新增**。
2. 輸入名稱，例如 `work`。命名規則：
   - 只能使用字母、數字、底線或連字號。
   - `default` 為保留名稱。
   - 名稱不能與同一索引標籤中其他帳號的名稱或顯示名稱相同（不區分大小寫）。
3. 保持勾選 **連結到預設帳號的設定和記錄**，即可共用你現有的設定；取消勾選則從預設設定的一份獨立副本開始。選擇前請先了解[帳號模式](#選擇連結帳號或獨立帳號)。
4. 按一下 **新增** 或按 Enter。PlanSwap 會建立帳號目錄，或重複使用同名的現有目錄。如果它回報有無法連結或複製的檔案，請查看清單：這些檔案會保持原樣。
5. 在新的一列上按一下 **登入**。會開啟一個終端機，請在其中完成官方用戶端的首次設定和登入。對於 Claude，也可以先切換到該帳號，再從 Claude Code 面板登入。
6. 如果該列仍顯示 **未登入**，請按一下面板標題列中的重新整理按鈕。關閉 PlanSwap 終端機也會重新整理清單。

新增或登入帳號不會讓編輯器使用它；準備好之後再切換過去。其他帳號會保持登入，不需要先登出。在終端機中登出只會結束該帳號自己的工作階段。

對於已登入的帳號，終端機圖示會以該列的帳號開啟官方 CLI，而不切換編輯器。終端機索引標籤的名稱為 `Claude (<label>)` 或 `Codex (<label>)`。

## 切換 Claude 帳號

1. 在非目前帳號的列上按一下 **切換到此帳號** 箭頭圖示。也可以按兩下卡片，或用 Tab 鍵將焦點移到卡片上後按 Enter。
2. 確認 **切換**。新的 Claude 工作階段會使用所選帳號。
3. 按一下橫幅中的 **重新載入視窗**，讓已開啟的 Claude 面板改用新帳號。重新載入之前，現有工作階段仍使用舊帳號。

命令選擇區中的 **Claude 帳號: 切換帳號**（Claude Account: Switch Account）命令會顯示帳號選擇器，切換時不會跳出確認對話方塊。

切換會修改同一台電腦上其他視窗共用的編輯器設定，因此這些視窗也會一起切換。凡是希望已開啟的 Claude 工作階段改用新帳號的視窗，都需要分別重新載入。

## 啟用並切換 Codex 帳號

### 首次啟用

開啟 **Codex** 索引標籤，按一下 **啟用 Codex 切換**。檢閱並確認它提出的變更：

- **WSL、本機 Linux 和其他遠端視窗**：PlanSwap 會在 `~/.profile` 和 `~/.bashrc` 中加入帶有標記的區塊，然後檢查 Bash 登入 shell 能否讀到所選帳號。如果它回報有衝突的 `CODEX_HOME` 指派或 shell 設定，請依照提示修正後再試一次。
- **原生 Windows**：PlanSwap 會管理你的使用者層級 `CODEX_HOME` 環境變數。如果你自己把 `CODEX_HOME` 設成了其他值，啟用會被拒絕。如果它已指向某個 PlanSwap 帳號目錄（`~/.codex-<name>`），PlanSwap 會接管它。

如果 Windows 上的 Codex 擴充功能設定為在 WSL 中執行，請在 WSL 視窗中管理其帳號，或先關閉 `chatgpt.runCodexInWindowsSubsystemForLinux`，再管理 Windows 帳號。

### 選擇帳號並使其生效

1. 新增並登入你想使用的帳號。
2. 儲存工作，然後按一下該帳號的 **切換到此帳號** 箭頭圖示。
3. 閱讀確認訊息，並依照適用於你的編輯器的重新啟動說明操作。

| 環境 | 選擇如何生效 |
| --- | --- |
| WSL 中的 Antigravity 或 VSCodium | 確認 **切換並重新啟動**。PlanSwap 會重新啟動編輯器的 WSL 伺服器；在每個中斷連線的視窗中按一下 **重新載入視窗**。如果無法自動重新啟動，請依照顯示的手動說明操作。 |
| WSL 中的 VS Code | 確認 **儲存選擇**。關閉連線到該發行版本的所有 VS Code 視窗，等待幾秒，然後重新開啟。 |
| WSL 中的其他編輯器 | 確認 **儲存選擇**，並依照對話方塊中的手動重新啟動說明操作。 |
| 原生 Windows | 確認 **儲存選擇**，完全結束編輯器，然後從開始功能表或工作列重新啟動。切換之前開啟的終端機仍使用舊帳號。 |
| 本機 Linux 或其他遠端視窗 | 確認 **儲存選擇**。然後依照對話方塊操作：重新啟動編輯器或遠端伺服器，使其以所選的 `CODEX_HOME` 啟動。 |

重新啟動 WSL 伺服器會中斷其編輯器視窗的連線，並關閉這些視窗的整合式終端機和 CLI 工作階段。僅 **重新載入視窗** 或 **重新啟動擴充功能主機** 並不會套用 Codex 帳號選擇。

完成重新啟動之前，橫幅會顯示已選擇帳號的名稱，醒目提示的列仍是本視窗中生效的帳號。若要再次查看重新啟動步驟，請在命令選擇區中執行 **套用 Codex 帳號：重新啟動或查看說明**（Apply Codex Account: Restart or Show Instructions，位於 **Codex 帳號** 類別下）。

重新啟動前改變主意了？按一下醒目提示（生效）列上的箭頭圖示，即可取消待生效的選擇，不需要重新啟動。

## 選擇連結帳號或獨立帳號

| 內容 | 已連結帳號 | 獨立帳號 |
| --- | --- | --- |
| 設定、規則和技能 | 使用預設帳號的 | 從一份副本開始，之後的修改各自獨立 |
| 提示記錄和工作階段 | 使用預設帳號的 | 保留自己的 |
| 登入 | 獨立 | 獨立 |
| Codex 記憶 | 獨立 | 獨立 |
| Codex 對話串資料庫 | 在 WSL 和 Linux 上共用；在原生 Windows 上獨立 | 獨立 |

連結並不保證另一個帳號能接續某個工作階段，尤其是跨不同的 ChatGPT 組織時。請勿同時以兩個帳號開啟同一個工作階段。

有些設定永遠不會連結：包含自身登入或提供者設定的設定檔（例如 API 金鑰輔助程式或自訂模型提供者）會保持獨立。結果訊息會列出這些檔案。

對於已連結的 Claude 帳號，PlanSwap 還會把預設帳號的 MCP 伺服器和各專案的信任設定複製到該帳號中。帳號登入後，還會複製預設帳號的首次執行狀態，讓 Claude Code 不再重複首次設定。

### 變更現有帳號的模式

轉換帳號之前：

1. 先切換到其他帳號。對於 Codex，請完成重新啟動，使該帳號既不是生效帳號，也不是已選擇帳號。
2. 關閉它的工作階段和 PlanSwap 終端機索引標籤。

然後：

- **連結到預設帳號**：在獨立的具名帳號列上按一下連結圖示，或執行對應產品的 **與預設帳號共用** 命令。該帳號自己的設定和記錄會移入預設帳號。與預設帳號不同的檔案會並排保留，供你手動合併，結果中會列出這些檔案。
- **與預設帳號拆分**：在已連結的具名帳號列上按一下中斷連線圖示。該帳號會取得一份自己的預設設定副本，並保留其登入和所有未連結的檔案。記錄和工作階段留在預設帳號中，不會複製回來。拆分不會復原連結時所做的合併。
- **重新連結**：變更預設帳號的設定後，或連結需要修復時，展開 **工具** 並按一下 **重新連結**。它會檢查該索引標籤中的所有已連結帳號，並列出需要處理的問題。對於 Claude，它還會從預設帳號更新這些帳號的 MCP 伺服器。

### Windows 上的連結

- 已連結的目錄使用目錄連接點（junction），不需要額外權限。
- 連結單一檔案需要開啟 Windows 開發人員模式，或以系統管理員身分執行編輯器。否則，PlanSwap 會提議改為將較小的設定檔複製一次；之後對這些副本的修改各自獨立。
- 日後若要正式連結這些檔案，請選擇 **開啟開發人員設定**，開啟開發人員模式，然後按一下 **重新連結**。它會建立缺少的連結，並把未修改的副本換成連結。
- 如果在 PlanSwap 詢問是否複製時，該帳號的 PlanSwap 終端機被開啟，轉換會停止且不做任何變更。請關閉終端機後再試一次。

## 查看和重新整理用量額度

用量條和百分比顯示的是**剩餘**額度。每項額度旁的時間長度（例如 `2 天 5 小時`）是距離重設的時間；將游標停留在上面可查看確切的日期和時間。已用完的額度會以紅色顯示 `0%` 及其重設時間。沒有用量列表示還沒有資料，而不是用量為零或額度無限。

查詢用量需要以 Claude 訂閱登入，或以 Codex 的 ChatGPT 方式登入（不支援 API 金鑰模式）。查詢會執行官方 CLI。

### 從側邊欄重新整理

**全部帳號** 旁邊的圖示：

- **重新整理目前帳號的用量額度**（重新整理圖示）：查詢目前的 Claude 帳號或生效的 Codex 帳號。該帳號可查詢時才會顯示。
- **重新整理全部帳號的用量額度**（堆疊圖層圖示）：逐一查詢該索引標籤中所有已登入的帳號，方便你在切換前比較。每一列會在查詢完成後立即更新。它從不切換帳號，你也可以在進度通知中取消。清單中至少有一個帳號可查詢時才會顯示。

在 Codex 索引標籤中，Codex 切換未啟用時，或在 Windows 上 Codex 於 WSL 中執行時，這兩個圖示都不會顯示。

命令選擇區中有相同的動作：**重新整理 Claude 用量額度**、**重新整理所有 Claude 帳號的用量額度**、**重新整理 Codex 用量額度** 和 **重新整理所有 Codex 帳號的用量額度**。

不到一分鐘前查詢過的帳號不會再次查詢。此時手動重新整理會顯示「用量額度在一分鐘內剛查詢過，請於 N 秒後再試。」任何查詢都算在內，包括自動查詢；對於 Claude，在其他視窗或終端機中進行的查詢也算。重新整理全部帳號時會略過這些帳號，並告訴你略過了幾個。

### 自動查詢

根據預設，PlanSwap 會自動查詢每個產品的目前帳號：視窗開啟幾秒後查詢一次，之後在視窗取得焦點時大約每 15 分鐘查詢一次。你可以在[設定](#變更語言和顯示設定)中變更間隔或關閉自動查詢。

其他列顯示的是各自上次查詢的結果。這些數值會在重設時間過後或 24 小時後消失；如果帳號在那之後重新登入過，也會隱藏。將游標停留在卡片的用量區域上可查看查詢時間。

### 狀態列

狀態列會顯示每個產品的短週期額度還剩多少，例如 `Claude 97% · Codex 82%`。當任一一般額度（包括較長週期的額度）剩餘 30% 或更少時，其背景會變為佈景主題的警告色；剩餘 10% 或更少時則變為錯誤色。

將游標停留在上面可查看一張表格：每個產品一列標題（電子郵件、方案，以及帳號可查詢時的重新整理圖示），每項一般額度一列。按一下它可開啟 PlanSwap。

## 重新命名或移除帳號

### 變更顯示名稱

將游標停留在某個具名帳號上或將焦點移到它上面，按一下名稱旁的鉛筆圖示。輸入顯示名稱，然後按 Enter、按一下勾號或按一下其他位置即可儲存；按 Esc 取消。

顯示名稱可以包含空格，最長 32 個字元，且不能與該索引標籤中其他帳號的名稱或顯示名稱相同。重新命名不會變更目錄或登入。預設帳號列和外部目錄列無法重新命名。

### 移除帳號

1. 先切換到其他帳號。對於 Codex，請完成重新啟動，使該帳號既不是生效帳號，也不是已選擇帳號。關閉該帳號的工作階段和終端機。
2. 按一下垃圾桶圖示並在該列中確認 **移除**，或在命令選擇區中使用對應產品的刪除命令。
3. 第二個對話方塊會詢問是否一併刪除帳號目錄。

如果保留目錄，只會移除清單項目及其顯示名稱。在你再次新增同名帳號之前，PlanSwap 不會再探索到該帳號。

如果刪除目錄，其登入和其中儲存的所有內容都會被永久刪除：

- 對於已連結帳號，預設帳號中的資料會保留；該帳號自己的登入、備份和其他未連結的檔案會被刪除。對於 Codex，這包括該帳號的記憶。
- 如果 PlanSwap 因帳號正在使用中而拒絕刪除，請關閉它列出的工作階段或處理程序後再試一次。

PlanSwap 啟動或重新整理時，會把在你的主目錄中找到、名稱有效的帳號目錄自動加入清單。

## 使用工具

展開帳號清單下方的 **工具**，即可使用該索引標籤專屬的動作：

| 工具 | 動作 |
| --- | --- |
| `CLAUDE.md` 或 `AGENTS.md` | 開啟目前 Claude 帳號或生效 Codex 帳號的規則檔案。檔案不存在時，會先詢問是否建立。 |
| 擴充功能設定 | 開啟官方 Claude Code 或 Codex 擴充功能的設定。 |
| 重新連結 | 修復該索引標籤中已連結帳號的連結（Claude：還會更新它們的 MCP 伺服器）。僅在有已連結帳號時顯示。 |
| 更新 CLI | 開啟一個終端機，執行該產品的更新命令。請在終端機中留意進度和提示；如果你是用其他方式安裝 CLI，可能需要用同樣的方式更新。 |

頁尾提供：

| 按鈕 | 動作 |
| --- | --- |
| 顯示 CLI 與擴充功能版本 | 顯示或隱藏一張卡片，列出兩個 CLI 和兩個官方擴充功能。未安裝的項目會顯示 **找不到**。 |
| 使用指南 | 在 GitHub 上開啟本指南。 |
| 重新載入視窗 | 立即重新載入目前視窗，不會詢問。 |
| 重新啟動擴充功能主機 | 立即重新啟動擴充功能主機，不會詢問。 |
| Star | 開啟 PlanSwap 的 GitHub 存放庫。 |

若要取得疑難排解報告，請在命令選擇區中執行 **PlanSwap: 預覽診斷報告**（PlanSwap: Preview Diagnostics Report）。閱讀之後，如需分享，請選擇 **複製報告**。報告以編號指稱帳號，不包含帳號名稱、電子郵件、目錄和憑證。不會自動上傳任何內容。

## 變更語言和顯示設定

按一下面板標題列中的設定圖示，或執行 **PlanSwap: 開啟 PlanSwap 設定**（PlanSwap: Open PlanSwap Settings）。變更會立即生效：

| 設定 | 預設值 | 用途 |
| --- | --- | --- |
| `planswap.language` | `auto` | 跟隨編輯器，或選擇 `en`、`zh-cn`、`zh-tw`、`es` 或 `ja`。 |
| `planswap.sidebar.showEmail` | `true` | 在側邊欄卡片上顯示帳號電子郵件。 |
| `planswap.sidebar.showFiveHourLimit` | `true` | 在卡片上顯示 5 小時額度。 |
| `planswap.sidebar.showWeeklyLimit` | `true` | 在卡片上顯示 7 天額度。 |
| `planswap.sidebar.showModelLimits` | `false` | 在卡片上額外顯示 Claude 的各模型額度。 |
| `planswap.claude.usageAutoRefresh` | `true` | 自動查詢 Claude 用量額度。 |
| `planswap.claude.usageRefreshMinutes` | `15` | 自動查詢 Claude 的間隔分鐘數，10–1440。 |
| `planswap.codex.usageAutoRefresh` | `true` | 自動查詢 Codex 用量額度。 |
| `planswap.codex.usageRefreshMinutes` | `15` | 自動查詢 Codex 的間隔分鐘數，5–1440。 |

關閉自動查詢後，重新整理圖示和命令仍然可用。側邊欄顯示設定不會影響狀態列。命令選擇區標題和側邊欄名稱會跟隨編輯器的顯示語言，而不是 `planswap.language`。

## 排解常見問題

| 現象 | 檢查項目 |
| --- | --- |
| Claude 仍在使用先前的帳號 | 重新載入視窗，讓已開啟的 Claude 面板改用新帳號。檢查是否有 PlanSwap 警告提示環境憑證或提供者設定覆寫了該帳號的登入。 |
| Codex 顯示有待生效的選擇 | 依照你的環境完成重新啟動。重新載入視窗無法取代重新啟動編輯器或 WSL 伺服器。 |
| 無法啟用 Codex 切換 | 查看列出的 shell 或 `CODEX_HOME` 衝突。在 Windows 上，檢查 Codex 是否設定為在 WSL 中執行。 |
| 某個帳號仍顯示 **未登入** | 使用該列的 **登入** 按鈕登入，然後重新整理。僅儲存在作業系統金鑰圈中的 Codex 登入無法偵測到，因為 PlanSwap 尋找的是該帳號的 `auth.json`。 |
| 兩個帳號觸發重複登入警告 | 兩者登入的是同一個帳號和工作區，因此在它們之間切換不會得到各自獨立的額度。請在其中一個帳號中登入你想要的身分。 |
| 沒有用量條，或查詢失敗 | 檢查該帳號是否以訂閱（Claude）或 ChatGPT（Codex）方式登入，以及是否已安裝 `claude` 命令（Claude）。手動重新整理並閱讀失敗訊息；如果提示正在冷卻，請稍候再重試。 |
| 設定或記錄沒有如預期共用 | 檢查連結標記，以及轉換或重新連結的結果。有些檔案會保持獨立或需要手動合併；在 Windows 上，檢查是否能建立檔案連結。 |
| 清單看起來不是最新的 | 按一下面板標題列中的重新整理按鈕。在其他視窗中所做的變更要重新整理後才會顯示。 |

關於登入被覆寫、工作階段共用的限制和 Windows 注意事項，請參閱[已知限制](../README.md#known-limitations)和[原生 Windows](../README.md#native-windows)。PlanSwap 在本機儲存哪些內容，以及查詢用量時如何使用官方用戶端，請參閱[隱私權](../README.md#privacy)。

## 停用切換或解除安裝

1. 把 Claude 切換回 `default` 並重新載入視窗。
2. 如果已啟用 Codex 切換，請執行 **停用 Codex 帳號切換**（Disable Codex Account Switching，位於命令選擇區的 **Codex 帳號** 類別下）並確認。這會移除 PlanSwap 的 shell 區塊（在 Windows 上則是它設定的使用者層級 `CODEX_HOME`），並清除選擇。已開啟的視窗在依照[選擇帳號並使其生效](#選擇帳號並使其生效)所述重新啟動之前，仍使用舊帳號。
3. 如有需要，可在擴充功能檢視中解除安裝 PlanSwap。

帳號目錄會保留。如果還想清除 PlanSwap 儲存的帳號清單、顯示名稱和用量記錄，請參閱[解除安裝說明](../README.md#uninstall)。這不會變更各帳號自己的檔案。
