# PlanSwap ユーザーガイド

[English](user-guide.md) · [简体中文](user-guide.zh-cn.md) · [繁體中文](user-guide.zh-tw.md) · [Español](user-guide.es.md) · **日本語**

PlanSwap を使うと、複数の Claude Code アカウントと Codex アカウントをサインインしたまま保持し、エディターがどのアカウントを使うかを選べます。このガイドでは、サイドバーの操作、アカウントの準備、切り替え、使用量の上限、日常のメンテナンスについて説明します。Claude と Codex は別々に管理され、一方を切り替えてももう一方は切り替わりません。

以下のボタン名は日本語 UI の表記です。アイコンにマウスを重ねると名前が表示されます。パネル下部のフッターにある本のアイコンから、このガイドを開けます。

## はじめる前に

必要なもの：

- VS Code 1.107 以降と互換性のあるエディター（VS Code、Antigravity IDE、VSCodium）。PlanSwap は WSL のリモートウィンドウ、ネイティブ Windows、ローカルの Linux デスクトップ、その他のリモートウィンドウで動作します。macOS には対応していません。
- そのウィンドウが動作する環境に、PlanSwap と公式の Claude Code 拡張機能または Codex 拡張機能（あるいは両方）がインストールされていること。
- ターミナルからサインインするには、その環境の PATH 上に `claude` または `codex` コマンドが必要です。コマンドが利用できない場合でも、使用量の確認には対応する公式拡張機能に同梱された CLI を利用できます。
- ネイティブ Windows 以外で Codex を切り替える場合：ログインシェルが Bash であること。

セットアップ方法と各エディターの検証状況については、[インストール手順](../README.md#install)と[対応エディター](../README.md#supported-editors)を参照してください。

## サイドバーの見かた

アクティビティバーの **PlanSwap** をクリックし、**Claude** タブまたは **Codex** タブを選びます。

- **既定のアカウント**：既存の設定で、通常は `~/.claude` または `~/.codex` です。Windows では `~` は Windows のユーザープロファイルを、WSL ではそのディストリビューション内のホームディレクトリを指します。エディターで `CLAUDE_CONFIG_DIR` がすでに設定されている場合、Claude のデフォルトディレクトリはそれに従います。
- **名前付きアカウント**：`work` や `personal` などのアカウントで、それぞれ専用のディレクトリ（例：`~/.claude-work`、`~/.codex-work`）を持ちます。
- **外部ディレクトリ**：エディターが現在使っているものの、PlanSwap のアカウント一覧にはないディレクトリです。PlanSwap では名前の変更や削除はできません。
- **強調表示された先頭の行**：現在のアカウントです。Codex の場合は、このウィンドウで有効なアカウントを示します。これは、選択済みで再起動を待っているアカウントとは異なる場合があります。
- **リンクバッジ**：リンク済みアカウントを示します。リンク済みアカウントは、既定のアカウントの設定・ルール・Skills・履歴・セッションを使います。サインインは独立したままです。

このガイドで使う用語：

- 「サインイン」と **ログイン** ボタンは同じ意味です。サインインしていない行には **未ログイン** と表示されます。
- 「リンク済み」は、UI でリンクバッジ付きで表示されるモードです。**既定のアカウントと共有**（Share with Default Account）コマンドで、独立アカウントをリンク済みアカウントに変換できます。
- Codex では、「有効な」アカウントはこのウィンドウが現在使っているアカウント、「選択中の」アカウントは次の再起動後に使われるアカウントです。

各カードには、アカウントの表示名とサインイン状態、さらに判明していればメールアドレス、プラン、使用量の上限が表示されます。アバターにマウスを重ねると、そのディレクトリが表示されます。

更新ボタンは 2 種類あります：

- パネルのタイトルバーにある更新ボタンは、両方のアカウント一覧を再スキャンし、サインイン情報を再読み込みします。
- **すべてのアカウント** の横にあるアイコンは、使用量の上限を確認します。[使用量の上限を確認して更新する](#使用量の上限を確認して更新する)を参照してください。

パネル下部のフッターは、どちらのタブでも常に表示されます。フッターのボタンでは、バージョンの表示、このガイドを開く、ウィンドウの再読み込み、Extension Host の再起動、GitHub リポジトリを開く、といった操作ができます。ボタンの下には、インストールされている PlanSwap のバージョンが表示されます。

## アカウントを追加してサインインする

Codex の場合は、先に[切り替えを有効化](#codex-アカウントを有効化して切り替える)してください。

1. 該当するタブで、**すべてのアカウント** の横にある **+ 追加** をクリックします。
2. `work` などの名前を入力します。名前のルール：
   - 英字、数字、アンダースコア、ハイフンを使います。
   - `default` は予約名です。
   - 同じタブ内のほかのアカウントの名前や表示名と同じ名前は使えません（大文字と小文字は区別しません）。
3. 別のアカウントで同じ作業を続けるには **既定のアカウントにリンク（おすすめ）** を選んだままにします。設定、履歴、セッションは共有され、サインインだけが別々です。仕事用と個人用を分けるには **独立アカウント** を選びます。現在の設定のコピーから始まります。選ぶ前に[アカウントのモード](#リンク済みアカウントと独立アカウントを選ぶ)を確認してください。
4. **追加** をクリックするか Enter キーを押します。PlanSwap はアカウントのディレクトリを作成します。同じ名前のディレクトリがすでにある場合はそれを再利用します。リンクやコピーができなかったファイルが報告された場合は、一覧を確認してください。それらのファイルはそのまま残ります。
5. 新しい行の **ログイン** をクリックします。ターミナルが開くので、そこで公式クライアントの初回セットアップとサインインを完了します。Claude の場合は、代わりにそのアカウントに切り替えてから Claude Code パネルでサインインすることもできます。
6. 行に **未ログイン** と表示されたままの場合は、パネルのタイトルバーにある更新ボタンをクリックします。PlanSwap のターミナルを閉じても一覧が更新されます。

アカウントを追加したりサインインしたりしても、エディターがそのアカウントを使うようにはなりません。準備ができたら切り替えてください。ほかのアカウントはサインインしたままなので、先にサインアウトする必要はありません。ターミナルでサインアウトすると、そのアカウントのセッションだけが終了します。

サインイン済みのアカウントでは、ターミナルアイコンをクリックすると、エディターを切り替えずに、その行のアカウントで公式 CLI が開きます。ターミナルのタブ名は `Claude (<label>)` または `Codex (<label>)` です。

## Claude アカウントを切り替える

1. 現在のアカウントではない行で、**このアカウントに切り替え** の矢印アイコンをクリックします。カードをダブルクリックするか、Tab キーでフォーカスして Enter キーを押しても切り替えられます。
2. **切り替え** で確定します。新しい Claude セッションは選択したアカウントを使います。`planswap.claude.confirmSwitch` をオフにすると、このダイアログなしで切り替わります。
3. バナーの **ウィンドウを再読み込み** をクリックすると、開いている Claude パネルが新しいアカウントに移ります。既存のセッションは、再読み込みするまで以前のアカウントのままです。

コマンドパレットの **Claude アカウント: アカウントを切り替え**（Claude Account: Switch Account）コマンドはアカウントの選択リストを表示し、確認ダイアログなしで切り替えます。

切り替えでは、同じマシン上のほかのウィンドウと共有されるエディター設定が変更されるため、それらのウィンドウも切り替わります。開いている Claude セッションで新しいアカウントを使いたいウィンドウは、それぞれ再読み込みしてください。

## Codex アカウントを有効化して切り替える

### 一度だけ有効化する

**Codex** タブを開き、**Codex の切り替えを有効化** をクリックします。提示される変更内容を確認して確定します：

- **WSL、ローカルの Linux、その他のリモートウィンドウ**：PlanSwap は `~/.profile` と `~/.bashrc` にマーカー付きのブロックを追加し、Bash のログインシェルが選択中のアカウントを読み込むことを確認します。競合する `CODEX_HOME` の設定やシェルの設定が報告された場合は、指摘された箇所を修正してからもう一度試してください。
- **ネイティブ Windows**：PlanSwap はユーザーレベルの環境変数 `CODEX_HOME` を管理します。`CODEX_HOME` を自分で別の値に設定している場合、有効化は拒否されます。すでに PlanSwap のアカウントディレクトリ（`~/.codex-<name>`）を指している場合は、PlanSwap がその管理を引き継ぎます。

Windows の Codex 拡張機能が WSL 内で実行するよう設定されている場合は、WSL ウィンドウからアカウントを管理するか、Windows のアカウントを管理する前に `chatgpt.runCodexInWindowsSubsystemForLinux` をオフにしてください。

### アカウントを選択して適用する

1. 使いたいアカウントを追加してサインインします。
2. 作業内容を保存してから、そのアカウントの **このアカウントに切り替え** の矢印アイコンをクリックします。
3. 確認メッセージを読み、お使いのエディターの再起動手順に従います。

| 環境 | 選択を反映する方法 |
| --- | --- |
| WSL 上の Antigravity または VSCodium | **切り替えて再起動** で確定します。PlanSwap がエディターの WSL サーバーを再起動します。切断された各ウィンドウで **ウィンドウを再読み込み** をクリックしてください。自動で再起動できない場合は、表示される手動の手順に従ってください。 |
| WSL 上の VS Code | **選択を保存** で確定します。そのディストリビューションに接続しているすべての VS Code ウィンドウを閉じ、数秒待ってから開き直します。 |
| WSL 上のその他のエディター | **選択を保存** で確定し、ダイアログに表示される手動の再起動手順に従います。 |
| ネイティブ Windows | **選択を保存** で確定し、エディターを完全に終了してから、スタートメニューまたはタスクバーから起動し直します。切り替え前に開いたターミナルは、以前のアカウントのままです。 |
| ローカルの Linux またはその他のリモートウィンドウ | **選択を保存** で確定します。続いてダイアログの指示に従い、エディターまたはリモートサーバーを再起動して、選択した `CODEX_HOME` で起動するようにします。 |

WSL サーバーを再起動すると、そのエディターのウィンドウが切断され、統合ターミナルと CLI セッションが閉じます。**ウィンドウを再読み込み** や **Extension Host を再起動** だけでは、Codex アカウントの選択は反映されません。

再起動が完了するまでは、選択中のアカウント名がバナーに表示され、強調表示された行はこのウィンドウで有効なアカウントのままです。再起動の手順をもう一度確認するには、コマンドパレットから **Codex アカウントを適用：再起動または手順を表示**（Apply Codex Account: Restart or Show Instructions、**Codex アカウント** の下に表示）を実行します。

再起動する前に気が変わった場合は、強調表示された（有効な）行の矢印アイコンをクリックします。保留中の選択が取り消され、再起動は不要です。

## リンク済みアカウントと独立アカウントを選ぶ

| 内容 | リンク済みアカウント | 独立アカウント |
| --- | --- | --- |
| 設定・ルール・Skills | 既定のアカウントのものを使用 | コピーから開始し、以後の編集は別々 |
| プロンプト履歴とセッション | 既定のアカウントのものを使用 | 独自に保持 |
| サインイン | 別々 | 別々 |
| Codex の Memories | 別々 | 別々 |
| Codex のスレッドデータベース | WSL と Linux では共有、ネイティブ Windows では別々 | 別々 |

リンクしていても、別のアカウントでセッションを再開できるとは限りません。特に ChatGPT の組織が異なる場合はなおさらです。同じセッションを 2 つのアカウントから同時に開かないでください。

一部の設定はリンクされません。Claude: サインインを提供または制限する `settings.json`（API キー、API キーヘルパー、強制ログイン方法など）はリンクされず、アカウントにはその設定を除いたコピーが作成されます。このコピーは以後の変更に追従しません。Codex: `forced_login_method` または `forced_chatgpt_workspace_id`（サインイン方法が異なるアカウントをサインアウトさせる設定）、あるいは `sqlite_home` を設定している `config.toml` はリンクされず、その設定を削除して **再リンク** を実行するまで、アカウントは Codex の組み込み設定で動作します。結果のメッセージには、そのファイル名と、Codex ではその設定名が表示されます。

リンク済みの Claude アカウントについては、PlanSwap は既定のアカウントの MCP サーバーとプロジェクトごとの信頼設定もアカウントにコピーします。アカウントがサインインした後は、既定のアカウントの初回セットアップの状態もコピーするため、Claude Code が初回セットアップを繰り返すことはありません。

### 既存アカウントのモードを変更する

アカウントを変換する前に：

1. 別のアカウントに切り替えます。Codex の場合は、再起動まで完了させ、そのアカウントが有効でも選択中でもない状態にします。
2. そのアカウントのセッションと、PlanSwap のターミナルタブを閉じます。

そのうえで：

- **既定のアカウントにリンク**：独立した名前付きアカウントの行でリンクアイコンをクリックするか、その製品の **既定のアカウントと共有** コマンドを実行します。アカウント独自の設定と履歴は既定のアカウントに移されます。既定のアカウントのものと内容が異なるファイルは、手動でマージできるよう並べて保持され、結果に一覧表示されます。
- **既定のアカウントとのリンクを解除**：リンク済みの名前付きアカウントの行でリンク解除アイコンをクリックします。アカウントは既定の設定の独自のコピーを持ち、サインインとリンクされていなかったファイルはそのまま残ります。履歴とセッションは既定のアカウントに残り、コピーし戻されることはありません。リンクを解除しても、リンク時に行われたマージは元に戻りません。
- **再リンク**：既定のアカウントのセットアップを変更した後や、リンクの修復が必要なときは、**ツール** の **再リンク** をクリックします。まず、そのタブのリンク済みアカウントを何も変更せずにすべてチェックします。問題がなければその旨を表示し、別の場所に向けたリンクやアカウント独自のファイルなど、そのままにしている項目も示します。問題があれば、不足しているリンクや使用中のアカウントなどをアカウントごとに 1 つの通知で示します。**修復** をクリックすると直せる項目を直します。既定のアカウントの内容が上書きされることはありません。Claude の場合は、既定のアカウントにあってリンク済みアカウントにない MCP サーバーや信頼済みプロジェクトもチェックし、**修復** で追加します。
- **自動チェック**：エディターの起動時と、そのウィンドウに戻ったとき（最短 10 分間隔）に、PlanSwap は同じチェックをバックグラウンドで実行します。通知を表示するのは **修復** で直せる問題があるときだけです。使用中のアカウントや別の場所に向けたリンクなどは、**再リンク** をクリックしたときにだけ表示されます。自動で修復することはありません。同じ問題は、エディターのウィンドウを複数開いていても 1 回だけ表示され、解決されないままなら 1 日後にもう一度表示されます。

### Windows でのリンク

- リンクされたディレクトリにはディレクトリジャンクションを使うため、追加の権限は必要ありません。
- 個々のファイルをリンクするには、Windows の開発者モードを有効にするか、エディターを管理者として実行する必要があります。どちらもない場合、PlanSwap は代わりに小さな設定ファイルを一度だけコピーすることを提案します。以後、それらのコピーへの編集は別々のままです。
- 後で正しくリンクするには、**開発者向け設定を開く** を選んで開発者モードをオンにし、**再リンク** をクリックします。不足しているリンクが作成され、変更されていないコピーはリンクに置き換えられます。
- PlanSwap がコピーについて確認している間にそのアカウントの PlanSwap ターミナルが開いた場合、変換は何も変更せずに中止されます。ターミナルを閉じてからもう一度試してください。
- Windows では、Codex のスレッドデータベース（`*.sqlite`）はリンクしません。Windows ではリンク経由で書き込んだ SQLite のデータが失われることがあるためです。各アカウントが自分のものを保持し、セッション、履歴、設定は引き続き共有されます。
- Windows では、実行中の Claude や Codex のプロセスがどのアカウントのものかを PlanSwap は判別できません。アカウントをリンク、リンク解除、削除する前に、そのアカウントのセッションと PlanSwap ターミナルのタブを閉じてください。CLI がすでに終了している場合も同様です。

## 使用量の上限を確認して更新する

使用量のバーとパーセンテージは **残り** の量を示します。[設定](#言語と表示の設定を変更する)で `planswap.usageDisplay` を `used` にすると、使用済みの量を表示します。各上限の横にある `2 日 5 時間` のような期間はリセットまでの時間です。バーにマウスを重ねると両方が表示されます（例：`残り 97%（使用済み 3%）`）。残りが 30% 以下になるとバーは黄色に、10% 以下になると赤に変わります。使用済みの量を表示している場合も同じです。この境目は `planswap.sidebar.warningThreshold` と `planswap.sidebar.errorThreshold` で変更できます。使い切った上限は、パーセンテージとリセット時刻が赤で表示されます。使用量の行がない場合は、まだデータがないことを意味し、使用量がゼロであることや上限がないことを意味するわけではありません。

使用量の確認には、Claude のサブスクリプションでのサインイン、または Codex の ChatGPT でのサインイン（API キーモードは不可）が必要です。確認は公式 CLI を実行して行われます。

### サイドバーから更新する

**すべてのアカウント** の横にあるアイコン：

- **現在のアカウントの使用量の上限を更新**（更新アイコン）：現在の Claude アカウント、または有効な Codex アカウントを確認します。そのアカウントを確認できる場合に表示されます。
- **すべてのアカウントの使用量の上限を更新**（重なったレイヤーのアイコン）：そのタブのサインイン済みアカウントをすべて 1 つずつ確認するので、切り替える前に比較できます。各行は確認が終わり次第更新されます。アカウントが切り替わることはなく、進行状況の通知から取り消せます。一覧の中に確認できるアカウントが 1 つ以上ある場合に表示されます。

Codex タブでは、Codex の切り替えが無効な間、また Windows で Codex が WSL 内で実行されている間は、どちらのアイコンも表示されません。

コマンドパレットにも同じ操作があります：**Claude の使用量の上限を更新**、**すべての Claude アカウントの使用量の上限を更新**、**Codex の使用量の上限を更新**、**すべての Codex アカウントの使用量の上限を更新**。

確認から 1 分経っていないアカウントは、再確認されません。その場合、手動で更新すると「使用量の上限は 1 分以内に確認済みです。N 秒後にもう一度お試しください。」と表示されます。自動確認を含むすべての確認が対象になり、Claude では別のウィンドウやターミナルで行われた確認も含まれます。すべてのアカウントの更新ではそのようなアカウントをスキップし、スキップした数を表示します。

### 自動確認

デフォルトでは、条件を満たすサインイン済みアカウントを自動確認します。まず現在の Claude アカウントまたは現在有効な Codex アカウントを、次にほかの登録済みアカウントを 1 つずつ確認します。最初の確認は起動の約 20 秒後です。ウィンドウにフォーカスがある間、スケジューラーはデフォルトで 120 秒ごとに対象を探し、各アカウントのキャッシュまたは前回の確認が 15 分以上古いかを判断します。待ち行列や新しいキャッシュにより確認時刻は変わるため、正確な 15 分ごとの更新ではありません。`planswap.usageAutoRefreshCurrentOnly` をオンにすると範囲を限定できます。間隔や自動確認の変更は[設定](#言語と表示の設定を変更する)で行えます。

ほかの行には、前回の確認結果が表示されます。値はリセット時刻を過ぎるか 24 時間経つと消え、その後アカウントがサインインし直した場合は非表示になります。

### おすすめのアカウント

現在のアカウントの一般的な上限のうち最も低いものが黄色の水準に達すると、一覧の上に緑色のカードが表示され、同じタブの別のサインイン済みアカウントをおすすめします。最も低い上限の残りが最も多いアカウントで、現在のアカウントより残りが多く、使い切った上限がないものが対象です。カードにはそのアカウントの上限と前回の確認からの経過時間が表示され、**切り替え** と **ターミナル** のボタンがあり、そのアカウントのカードにあるボタンと同じ動作をします（Claude: 通常の確認が続きます。Codex: アカウントが選択され、エディターのサーバーの再起動が続きます）。Codex タブでは、選択したアカウントがサーバーの再起動を待っている間はカードを表示しません。モデル別の上限は比較されません。カード自体は何も問い合わせないので、数値はそのアカウントの前回の確認時点のものです。

仕事用アカウントなどをおすすめから外すには、そのカードの電球アイコンをクリックします。もう一度クリックすると戻ります。[設定](#言語と表示の設定を変更する)で `planswap.sidebar.showRecommendation` をオフにすると、カードと電球アイコンを非表示にできます。

### ステータスバー

ステータスバーには、各製品の短期の上限が表示されます（例：`Claude 97% · Codex 82%`）。既定では残りの量で、`planswap.usageDisplay` が `used` のときは使用済みの量です。残り少なくなっているのが長期の上限のときは、代わりにその上限が期間付きで表示されます（例：`Claude 2%（7 日）`）。その数値は数日後にしか回復しないためです。長期のものも含め、いずれかの一般的な上限の残りが 30% 以下になると背景がテーマの警告色に、10% 以下になるとエラー色に変わります。これらのしきい値の変更、1 つの製品だけの表示、項目の左側への移動や非表示もできます（[言語と表示の設定を変更する](#言語と表示の設定を変更する)）。

マウスを重ねると、製品ごとに 1 行のヘッダー行（メールアドレス、プラン、確認できるアカウントでは更新アイコン）と、一般的な上限ごとに 1 行を持つ表が表示されます。クリックすると PlanSwap が開きます。 `planswap.sidebar.showEmail` がオフの場合、ツールチップにはメールアドレスではなくアカウントのラベルを表示します。ユーザーが設定した名前や別名は変更しません。

## アカウントの名前変更と削除

### 表示名を変更する

名前付きアカウントにマウスを重ねるかフォーカスし、名前の横にある鉛筆アイコンをクリックします。表示名を入力し、Enter キーを押すか、チェックマークをクリックするか、ほかの場所をクリックすると保存されます。Escape キーで取り消せます。

表示名にはスペースを含めることができ、最大 32 文字までです。そのタブのほかのアカウントの名前や表示名と同じにはできません。名前を変更しても、ディレクトリやサインインは変わりません。デフォルトの行と外部ディレクトリの行は名前を変更できません。

### アカウントを削除する

1. 先に別のアカウントに切り替えます。Codex の場合は、再起動まで完了させ、そのアカウントが有効でも選択中でもない状態にします。そのアカウントのセッションとターミナルを閉じます。
2. ゴミ箱アイコンをクリックして行内で **削除** で確定するか、コマンドパレットでその製品の削除コマンドを使います。
3. 2 つ目のダイアログで、アカウントのディレクトリも削除するかどうかを確認されます。

ディレクトリを残す場合は、一覧の項目とその表示名だけが削除されます。同じ名前を再び追加するまで、PlanSwap はそのアカウントを検出しなくなります。

ディレクトリを削除する場合は、そのサインイン情報と、ディレクトリに保存されているものがすべて完全に削除されます：

- リンク済みアカウントの場合、既定のアカウント内のデータは残ります。アカウント独自のサインイン情報、バックアップ、リンクされていなかったその他のファイルは削除されます。Codex の場合は、アカウントの Memories も含まれます。
- アカウントが使用中であるため PlanSwap が削除を拒否した場合は、表示されたセッションやプロセスを閉じてからもう一度試してください。

PlanSwap がホームディレクトリで見つけた、有効な名前を持つアカウントディレクトリは、起動時または更新時に自動的に一覧に追加されます。

## ツールを使う

アカウント一覧の下にある **ツール** には、そのタブ固有の操作があります：

| ツール | 操作 |
| --- | --- |
| `CLAUDE.md` または `AGENTS.md` | 現在の Claude アカウント、または有効な Codex アカウントのルールファイルを開きます。ファイルがない場合は、作成する前に確認します。 |
| Claude の設定 または Codex の設定 | 公式の Claude Code 拡張機能または Codex 拡張機能の設定を開きます（PlanSwap 自体の設定は、パネルのタイトルバーの歯車にあります）。 |
| CLI を更新 | その製品の更新コマンドを実行するターミナルを開きます。進行状況とプロンプトはそのターミナルで確認してください。CLI を別の方法でインストールした場合は、その方法で更新する必要があることがあります。 |
| 再リンク | このタブのリンク済みアカウントのリンクをチェックし、見つかった問題に **修復** を提示します（Claude ではそれらの MCP サーバーも対象）。リンク済みアカウントがある場合にのみ表示されます。 |

フッターには次のボタンがあります：

| ボタン | 操作 |
| --- | --- |
| CLI と拡張機能のバージョンを表示 | 両方の CLI と両方の公式拡張機能を一覧にしたカードの表示・非表示を切り替えます。インストールされていないものには **見つかりません** と表示されます。 |
| 使い方 | GitHub でこのガイドを開きます。 |
| ウィンドウを再読み込み | 確認なしで、現在のウィンドウをすぐに再読み込みします。 |
| Extension Host を再起動 | 確認なしで、Extension Host をすぐに再起動します。 |
| Star | PlanSwap の GitHub リポジトリを開きます。 |

トラブルシューティング用のレポートを取得するには、コマンドパレットから **PlanSwap: 診断レポートをプレビュー**（PlanSwap: Preview Diagnostics Report）を実行します。内容を確認し、共有する場合は **レポートをコピー** を選びます。レポートではアカウントを番号で表し、アカウント名、メールアドレス、ディレクトリ、認証情報は含まれません。自動でアップロードされることはありません。

## 言語と表示の設定を変更する

パネルのタイトルバーにある設定アイコンをクリックするか、**PlanSwap: PlanSwap の設定を開く**（PlanSwap: Open PlanSwap Settings）を実行します。設定エディターでは、全般、サイドバー、ステータスバー、Claude、Codex のグループに分かれています。下の表も同じ順序です。設定を探すには、表の設定名を設定エディターの検索ボックスに入力します。変更はすぐに反映されます：

| 設定 | デフォルト | 用途 |
| --- | --- | --- |
| `planswap.language` | `auto` | エディターに合わせるか、`en`、`zh-cn`、`zh-tw`、`es`、`ja` から選びます。 |
| `planswap.usageDisplay` | `remaining` | サイドバーとステータスバーの使用量のバーとパーセンテージに、残りの量（`remaining`）と使用済みの量（`used`）のどちらを表示するか。色は常に残りの量に基づきます。 |
| `planswap.usageAutoRefreshCurrentOnly` | `false` | オンの場合は現在の Claude アカウントと現在有効な Codex アカウントだけを、オフの場合はほかの条件を満たす登録済みアカウントも自動確認します。手動更新には影響しません。 |
| `planswap.usageCheckIntervalSeconds` | `120` | スケジューラーの確認周期（秒、30–600）。確認時期が来たアカウントを探します。正確な確認時刻は保証しません。 |
| `planswap.notifications.enabled` | `true` | 現在の Claude または Codex アカウントの 5 時間の上限または 7 日間の上限が次のしきい値まで下がったときに一度通知します。上限に達したときは通知しません。Claude Code と Codex が自分で知らせます。 |
| `planswap.notifications.threshold` | `20` | 残りの割合がこの値以下になると通知します。1–99。 |
| `planswap.sidebar.showEmail` | `true` | サイドバーのカードとステータスバーのツールチップにメールアドレスを表示します。非表示の場合、ツールチップにはアカウントのラベルを表示します。 |
| `planswap.sidebar.showFiveHourLimit` | `true` | カードに 5 時間の上限を表示します。 |
| `planswap.sidebar.showWeeklyLimit` | `true` | カードに 7 日間の上限を表示します。 |
| `planswap.sidebar.showModelLimits` | `false` | カードに Claude のモデル別の上限を追加します。 |
| `planswap.sidebar.warningThreshold` | `30` | 残りの割合がこの値以下で警告色（0–100）。推奨が有効な場合は、アカウント推奨のしきい値にもなります。 |
| `planswap.sidebar.errorThreshold` | `10` | 残りの割合がこの値以下になると、カードのバーがエラー色になります。0–100。警告色より優先されます。 |
| `planswap.sidebar.showRecommendation` | `true` | [おすすめのアカウント](#おすすめのアカウント)のカードと、カードの電球アイコンを表示します。 |
| `planswap.statusBar.enabled` | `true` | ステータスバーに PlanSwap の項目を表示します。 |
| `planswap.statusBar.products` | `both` | ステータスバーに表示する製品：`both`、`claude`、`codex`。バックグラウンドの使用量更新は無効になりません。 |
| `planswap.statusBar.warningThreshold` | `30` | 残りの割合がこの値以下で警告色（0–100）。 |
| `planswap.statusBar.errorThreshold` | `10` | 残りの割合がこの値以下でエラー色（0–100）。警告色より優先されます。 |
| `planswap.statusBar.alignment` | `right` | ステータスバーの表示位置：`left` または `right`。 |
| `planswap.claude.confirmSwitch` | `true` | サイドバーから Claude アカウントを切り替える前に確認します。Codex の切り替えは常に確認します。オフにすると、フォーカスのある行でのダブルクリックまたは Enter ですぐに切り替わります。 |
| `planswap.claude.usageAutoRefresh` | `true` | 条件を満たす Claude アカウントを自動確認します。対象範囲は `planswap.usageAutoRefreshCurrentOnly` に従います。 |
| `planswap.claude.usageRefreshMinutes` | `15` | Claude の自動更新の時間のしきい値（分、10–1440）。使用量キャッシュまたは前回の確認から判断します。正確な更新予定ではありません。 |
| `planswap.claude.usageTimeoutSeconds` | `30` | Claude の使用量確認がタイムアウトするまでの秒数（10–120）。自動・手動の確認に適用されます。 |
| `planswap.codex.usageAutoRefresh` | `true` | 条件を満たす Codex アカウントを自動確認します。対象範囲は `planswap.usageAutoRefreshCurrentOnly` に従います。 |
| `planswap.codex.usageRefreshMinutes` | `15` | Codex の自動更新の時間のしきい値（分、5–1440）。使用量キャッシュまたは前回の確認から判断します。正確な更新予定ではありません。 |
| `planswap.codex.usageTimeoutSeconds` | `15` | Codex の使用量確認がタイムアウトするまでの秒数（5–120）。自動・手動の確認に適用されます。 |

自動確認をオフにしても、更新アイコンとコマンドは引き続き使えます。メールアドレスの設定はステータスバーのツールチップにも適用されます。サイドバーの上限と推奨の表示設定はステータスバーには影響しません。コマンドパレットのタイトルとサイドバーの名前は、`planswap.language` ではなくエディターの表示言語に従います。

## よくある問題の解決

| 症状 | 確認すること |
| --- | --- |
| Claude が以前のアカウントを使い続ける | ウィンドウを再読み込みして、開いている Claude パネルを新しいアカウントに移します。環境の認証情報やプロバイダーの設定がアカウントのサインインより優先されているという PlanSwap の警告が出ていないか確認してください。 |
| Codex に保留中の選択が表示される | お使いの環境に応じた再起動を完了してください。ウィンドウの再読み込みは、エディターや WSL サーバーの再起動の代わりにはなりません。 |
| Codex の切り替えを有効化できない | 表示されたシェルまたは `CODEX_HOME` の競合を確認してください。Windows では、Codex が WSL 内で実行するよう設定されていないか確認してください。 |
| アカウントに **未ログイン** と表示されたまま | その行の **ログイン** ボタンでサインインしてから、更新してください。PlanSwap はアカウントの `auth.json` を探すため、オペレーティングシステムのキーリングにのみ保存された Codex のサインインは検出できません。 |
| 2 つのアカウントで重複サインインの警告が出る | 両方が同じアカウントとワークスペースでサインインしているため、切り替えても使用量の上限は別になりません。どちらかで目的のアカウントにサインインし直してください。 |
| 使用量のバーが表示されない、または確認に失敗した | アカウントがサブスクリプション（Claude）または ChatGPT（Codex）でサインインしていること、`claude` コマンドがインストールされていること（Claude）を確認してください。手動で更新して失敗メッセージを確認し、確認間隔の制限（クールダウン）が表示された場合は、しばらく待ってから再試行してください。CLI が時間内に応答しなかったと表示された場合は、`planswap.claude.usageTimeoutSeconds` または `planswap.codex.usageTimeoutSeconds` を大きくしてください。 |
| 設定や履歴が期待どおりに共有されない | リンクバッジと、変換または再リンクの結果を確認してください。一部のファイルは別々のまま残るか、手動でのマージが必要です。Windows では、ファイルのリンクが利用できるか確認してください。 |
| 一覧が古いように見える | パネルのタイトルバーにある更新ボタンをクリックしてください。別のウィンドウで行った変更は、更新後に反映されます。 |

### すべてのアカウントに適用されるサインイン

次のものは各アカウント自体のサインインより優先されるため、どれかが設定されている間は Claude のアカウントを切り替えても効果がありません。環境内に見つかると PlanSwap が警告します：

- API キー、認証トークン、長期間有効な OAuth トークン：`ANTHROPIC_API_KEY`、`ANTHROPIC_AUTH_TOKEN`、`CLAUDE_CODE_OAUTH_TOKEN`
- 名前付きの Anthropic プロファイル（`ANTHROPIC_PROFILE`）、またはフェデレーション変数（`ANTHROPIC_FEDERATION_RULE_ID` と `ANTHROPIC_ORGANIZATION_ID`）
- クラウドプロバイダーの設定：`CLAUDE_CODE_USE_BEDROCK`、`CLAUDE_CODE_USE_VERTEX`、`CLAUDE_CODE_USE_FOUNDRY`

API キーを使わない Claude Console のサインインはアカウントのディレクトリの外（`~/.config/anthropic`、Windows では `%APPDATA%\Anthropic`）に保存され、マシン上のすべての claude.ai ログインをサインアウトさせるため、アカウントごとに保持できません（[Claude Code の認証](https://code.claude.com/docs/en/authentication#sign-in-without-an-api-key)）。

### Windows の OneDrive

ユーザーフォルダーが OneDrive で同期されている場合、PlanSwap は警告します。OneDrive の同期は Claude Code の `.claude.json` を破損させることが知られており、すべてのアカウントのディレクトリがそのフォルダー内にあります。

ほかの制限（別のアカウントのセッションを続ける場合など）については、[既知の制限事項](../README.md#known-limitations)を参照してください。PlanSwap が読み取り、保存、送信する内容については、[プライバシー](privacy.md)を参照してください。

## 切り替えの無効化とアンインストール

1. Claude を `default` に切り替え直し、ウィンドウを再読み込みします。
2. Codex の切り替えが有効な場合は、**Codex アカウント切り替えを無効化**（Disable Codex Account Switching、コマンドパレットの **Codex アカウント** の下）を実行して確定します。PlanSwap のシェルブロック（Windows ではユーザーレベルの `CODEX_HOME`）が削除され、選択が解除されます。開いているウィンドウは、[アカウントを選択して適用する](#アカウントを選択して適用する)で説明した方法で再起動するまで、以前のアカウントのままです。
3. 必要に応じて、拡張機能ビューから PlanSwap をアンインストールします。

アカウントのディレクトリは残ります。PlanSwap が保存したアカウント一覧、表示名、使用量の記録も消去するには、[アンインストール手順](../README.md#uninstall)を参照してください。この操作でアカウント自体のファイルが変更されることはありません。
