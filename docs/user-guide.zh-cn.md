# PlanSwap 使用说明

[English](user-guide.md) · **简体中文** · [繁體中文](user-guide.zh-tw.md) · [Español](user-guide.es.md) · [日本語](user-guide.ja.md)

PlanSwap 让你同时保持多个 Claude Code 和 Codex 账号的登录状态，并选择编辑器使用哪一个。本说明介绍侧边栏的各项控件、账号设置、切换、用量额度和日常维护。Claude 和 Codex 相互独立管理：切换其中一个不会切换另一个。

下文按钮名称采用中文界面的文字。将鼠标悬停在图标上可以看到它的名称。面板底部页脚中的书本图标可打开本说明。

## 开始之前

你需要：

- 兼容 VS Code 1.107 及以上版本的编辑器（VS Code、Antigravity IDE 或 VSCodium）。PlanSwap 可在 WSL 远程窗口、原生 Windows、本地 Linux 桌面或其他远程窗口中运行。不支持 macOS。
- 在该窗口运行的环境中安装 PlanSwap，以及官方 Claude Code 和/或 Codex 插件。
- 该环境的 PATH 中有 `claude` 命令，用于在终端登录和查询 Claude 用量额度；有 `codex` 命令，用于在终端登录 Codex。安装了 Codex 插件时，即使没有该命令也能查询 Codex 用量额度。
- 在原生 Windows 以外的环境中切换 Codex：登录 shell 须为 Bash。

安装步骤以及各编辑器的测试程度，请参阅[安装说明](../README.md#install)和[支持的编辑器](../README.md#supported-editors)。

## 熟悉侧边栏

在活动栏中点击 **PlanSwap**，然后选择 **Claude** 或 **Codex** 标签页。

- **默认账号**：你现有的配置，通常是 `~/.claude` 或 `~/.codex`。在 Windows 上，`~` 指你的 Windows 用户目录；在 WSL 中，指该发行版内的主目录。如果编辑器已经设置了 `CLAUDE_CONFIG_DIR`，Claude 的默认目录会随之改变。
- **命名账号**：如 `work` 或 `personal` 这样的账号，每个都有自己的目录，例如 `~/.claude-work` 或 `~/.codex-work`。
- **外部目录**：编辑器当前正在使用、但不在 PlanSwap 账号列表中的目录。它不能在 PlanSwap 中重命名或删除。
- **高亮的第一行**：当前账号。对 Codex 而言，这是本窗口中生效的账号，可能与你已选择、正在等待重启的账号不同。
- **链接标记**：表示链接账号，它使用默认账号的设置、规则、技能、历史和会话，登录保持独立。

本说明中的用语：

- “登录”即 **登录** 按钮；未登录的行显示 **未登录**。
- “链接”是界面中带链接标记的模式。**与默认账号共享** 命令可把独立账号改为链接账号。
- 对 Codex 而言，“生效账号”是本窗口当前使用的账号；“已选账号”是下次重启后将使用的账号。

每张卡片显示账号的显示名和登录状态，获取到之后还会显示邮箱、套餐和用量额度。将鼠标悬停在头像上可查看它的目录。

刷新按钮有两种：

- 面板标题栏中的刷新按钮会重新扫描两个账号列表，并重新加载登录信息。
- **全部账号** 旁边的图标用于查询用量额度。参见[查看和刷新用量额度](#查看和刷新用量额度)。

面板底部的页脚在两个标签页上都始终可见。其中的按钮分别用于显示版本、打开本说明、重新加载窗口、重启扩展宿主和打开 GitHub 仓库。按钮下方显示已安装的 PlanSwap 版本。

## 添加并登录账号

对于 Codex，请先[启用切换](#启用并切换-codex-账号)。

1. 在相应标签页中，点击 **全部账号** 旁边的 **+ 添加**。
2. 输入名称，例如 `work`。命名规则：
   - 只能使用字母、数字、下划线或连字符。
   - `default` 为保留名。
   - 名称不能与同一标签页中其他账号的名称或显示名相同（不区分大小写）。
3. 保持勾选 **链接到默认账号的配置和历史**，即可共用你现有的设置；取消勾选则从默认配置的一份独立副本开始。选择前请先了解[账号模式](#选择链接账号或独立账号)。
4. 点击 **添加** 或按回车。PlanSwap 会创建账号目录，或复用同名的已有目录。如果它报告有无法链接或复制的文件，请查看列表：这些文件保持原样。
5. 在新行上点击 **登录**。会打开一个终端，在其中完成官方客户端的首次设置和登录。对于 Claude，也可以先切换到该账号，再在 Claude Code 面板中登录。
6. 如果该行仍显示 **未登录**，点击面板标题栏中的刷新按钮。关闭 PlanSwap 终端也会刷新列表。

添加或登录账号不会让编辑器使用它；准备好后再切换过去。其他账号保持登录，不需要先退出。在终端中退出登录只会结束该账号自己的会话。

对于已登录的账号，终端图标会用该行的账号打开官方 CLI，而不切换编辑器。终端标签页名为 `Claude (<label>)` 或 `Codex (<label>)`。

## 切换 Claude 账号

1. 在非当前账号的行上点击 **切换到此账号** 箭头图标。也可以双击卡片，或用 Tab 键聚焦卡片后按回车。
2. 确认 **切换**。新的 Claude 会话将使用所选账号。关闭 `planswap.claude.confirmSwitch` 后，切换时不再弹出此对话框。
3. 点击横幅中的 **重新加载窗口**，让已打开的 Claude 面板改用新账号。重新加载之前，已有会话仍使用旧账号。

命令面板中的 **Claude 账号: 切换账号**（Claude Account: Switch Account）命令会显示账号选择器，切换时不弹出确认对话框。

切换会修改同一台机器上其他窗口共用的编辑器设置，因此这些窗口也会一起切换。凡是希望已打开的 Claude 会话改用新账号的窗口，都需要分别重新加载。

## 启用并切换 Codex 账号

### 首次启用

打开 **Codex** 标签页，点击 **启用 Codex 切换**。查看并确认它提出的修改：

- **WSL、本地 Linux 和其他远程窗口**：PlanSwap 会在 `~/.profile` 和 `~/.bashrc` 中添加带标记的代码块，然后检查 Bash 登录 shell 能否读到所选账号。如果它报告存在冲突的 `CODEX_HOME` 赋值或 shell 配置，请按提示修正后重试。
- **原生 Windows**：PlanSwap 管理你的用户级 `CODEX_HOME` 环境变量。如果你自己把 `CODEX_HOME` 设成了其他值，启用会被拒绝。如果它已指向某个 PlanSwap 账号目录（`~/.codex-<name>`），PlanSwap 会接管它。

如果 Windows 上的 Codex 插件设置为在 WSL 中运行，请在 WSL 窗口中管理其账号，或者先关闭 `chatgpt.runCodexInWindowsSubsystemForLinux`，再管理 Windows 账号。

### 选择账号并使其生效

1. 添加并登录你想用的账号。
2. 保存工作，然后点击该账号的 **切换到此账号** 箭头图标。
3. 阅读确认信息，并按照适用于你的编辑器的重启说明操作。

| 环境 | 选择如何生效 |
| --- | --- |
| WSL 中的 Antigravity 或 VSCodium | 确认 **切换并重启**。PlanSwap 会重启编辑器的 WSL 服务端；在每个断开连接的窗口中点击 **重新加载窗口**。如果无法自动重启，请按显示的手动说明操作。 |
| WSL 中的 VS Code | 确认 **保存选择**。关闭连接到该发行版的所有 VS Code 窗口，等待几秒，然后重新打开。 |
| WSL 中的其他编辑器 | 确认 **保存选择**，并按对话框中的手动重启说明操作。 |
| 原生 Windows | 确认 **保存选择**，完全退出编辑器，然后从开始菜单或任务栏重新启动。切换之前打开的终端仍使用旧账号。 |
| 本地 Linux 或其他远程窗口 | 确认 **保存选择**。然后按对话框操作：重启编辑器或远程服务端，使其以所选的 `CODEX_HOME` 启动。 |

重启 WSL 服务端会断开其编辑器窗口，并关闭这些窗口的集成终端和 CLI 会话。仅 **重新加载窗口** 或 **重启扩展宿主** 不会应用 Codex 账号选择。

完成重启之前，横幅会显示已选账号的名称，高亮行仍是本窗口中生效的账号。要再次查看重启步骤，请在命令面板中运行 **应用 Codex 账号：重启或查看说明**（Apply Codex Account: Restart or Show Instructions，位于 **Codex 账号** 分类下）。

重启前改变主意了？点击高亮（生效）行上的箭头图标即可取消待生效的选择，无需重启。

## 选择链接账号或独立账号

| 内容 | 链接账号 | 独立账号 |
| --- | --- | --- |
| 设置、规则和技能 | 使用默认账号的 | 从一份副本开始，之后的修改各自独立 |
| 提示历史和会话 | 使用默认账号的 | 保留自己的 |
| 登录 | 独立 | 独立 |
| Codex 记忆 | 独立 | 独立 |
| Codex 会话数据库 | 在 WSL 和 Linux 上共享；在原生 Windows 上独立 | 独立 |

链接并不保证另一个账号能续接某个会话，尤其是跨不同的 ChatGPT 组织时。不要同时用两个账号打开同一个会话。

有些设置永远不会链接：包含自身登录或提供方配置的设置文件（例如 API 密钥辅助程序或自定义模型提供方）会保持独立。结果消息会列出这些文件。

对于链接的 Claude 账号，PlanSwap 还会把默认账号的 MCP 服务器和各项目的信任设置复制到该账号中。账号登录后，还会复制默认账号的首次运行状态，使 Claude Code 不再重复首次设置。

### 更改现有账号的模式

转换账号之前：

1. 先切换到其他账号。对于 Codex，请完成重启，使该账号既不是生效账号，也不是已选账号。
2. 关闭它的会话和 PlanSwap 终端标签页。

然后：

- **链接到默认账号**：在独立的命名账号行上点击链接图标，或运行对应产品的 **与默认账号共享** 命令。该账号自己的设置和历史会移入默认账号。与默认账号不同的文件会并排保留，供你手动合并，结果中会列出这些文件。
- **与默认账号拆分**：在链接的命名账号行上点击断开图标。该账号会获得一份自己的默认配置副本，并保留其登录和所有未链接的文件。历史和会话留在默认账号中，不会复制回来。拆分不会撤销链接时所做的合并。
- **重新链接**：修改默认账号的设置后，或链接需要修复时，点击 **工具** 中的 **重新链接**。它会检查该标签页中的所有链接账号，并列出需要处理的问题。对于 Claude，它还会从默认账号更新这些账号的 MCP 服务器。

### Windows 上的链接

- 链接的目录使用目录联接（junction），无需额外权限。
- 链接单个文件需要开启 Windows 开发人员模式，或以管理员身份运行编辑器。否则，PlanSwap 会提议改为把较小的配置文件复制一次；之后对这些副本的修改各自独立。
- 以后要正式链接这些文件，请选择 **打开开发者设置**，开启开发人员模式，然后点击 **重新链接**。它会创建缺失的链接，并把未修改的副本换成链接。
- 如果在 PlanSwap 询问是否复制时该账号的 PlanSwap 终端被打开，转换会停止且不做任何更改。关闭终端后重试。

## 查看和刷新用量额度

用量条和百分比显示的是**剩余**额度（将 `planswap.usageDisplay` 设为 `used` 可改为显示已用量）。每项额度旁边的时长（如 `2天5小时`）是距离重置的时间。将鼠标悬停在用量条上可查看剩余和已用的比例，例如 `剩余 97%（已用 3%）`。已用完的额度会以红色显示 `0%` 及其重置时间。没有用量行表示还没有数据，而不是用量为零或额度无限。

查询用量需要以 Claude 订阅登录，或以 Codex 的 ChatGPT 方式登录（不支持 API 密钥模式）。查询会运行官方 CLI。

### 从侧边栏刷新

**全部账号** 旁边的图标：

- **刷新当前账号的用量额度**（刷新图标）：查询当前 Claude 账号或生效的 Codex 账号。该账号可查询时显示。
- **刷新全部账号的用量额度**（层叠图标）：逐个查询该标签页中所有已登录的账号，方便你在切换前比较。每一行在查询完成后立即更新。它从不切换账号，你也可以在进度通知中取消。列表中至少有一个账号可查询时显示。

在 Codex 标签页中，Codex 切换未启用时，或在 Windows 上 Codex 运行于 WSL 中时，这两个图标都不会显示。

命令面板中有相同的操作：**刷新 Claude 用量额度**、**刷新所有 Claude 账号的用量额度**、**刷新 Codex 用量额度** 和 **刷新所有 Codex 账号的用量额度**。

不到一分钟前查询过的账号不会再次查询。此时手动刷新会显示“用量额度一分钟内刚查询过，请 N 秒后再试。”任何查询都算在内，包括自动查询；对于 Claude，在其他窗口或终端中进行的查询也算。刷新全部账号时会跳过这些账号，并告诉你跳过了几个。

### 自动查询

默认情况下，PlanSwap 会自动查询每个产品的当前账号：窗口打开几秒后查询一次，之后在窗口获得焦点时大约每 15 分钟查询一次。你可以在[设置](#更改语言和显示设置)中更改间隔或关闭自动查询。

其他行显示的是各自上次查询的结果。这些数值会在重置时间过后或 24 小时后消失，如果账号此后重新登录过，也会隐藏。

### 状态栏

状态栏显示每个产品的短周期额度还剩多少，例如 `Claude 97% · Codex 82%`。当任一通用额度（包括较长周期的额度）剩余 30% 或更少时，其背景会变为主题的警告色；剩余 10% 或更少时变为错误色。你可以更改这些阈值、只显示一个产品、把该项移到左侧或隐藏它（[更改语言和显示设置](#更改语言和显示设置)）。

悬停可查看一张表格：每个产品一行表头（邮箱、套餐，以及账号可查询时的刷新图标），每项通用额度一行。点击它可打开 PlanSwap。

## 重命名或删除账号

### 更改显示名

悬停或聚焦某个命名账号，点击其名称旁的铅笔图标。输入显示名，然后按回车、点击对勾或点击其他位置保存；按 Esc 取消。

显示名可以包含空格，最长 32 个字符，且不能与该标签页中其他账号的名称或显示名相同。重命名不会改变目录或登录。默认账号行和外部目录行不能重命名。

### 删除账号

1. 先切换到其他账号。对于 Codex，请完成重启，使该账号既不是生效账号，也不是已选账号。关闭该账号的会话和终端。
2. 点击垃圾桶图标并在该行中确认 **删除**，或在命令面板中使用对应产品的删除命令。
3. 第二个对话框会询问是否同时删除账号目录。

如果保留目录，只会删除列表条目及其显示名。在你再次添加同名账号之前，PlanSwap 不会再发现该账号。

如果删除目录，其登录和其中保存的所有内容都会被永久删除：

- 对于链接账号，默认账号中的数据会保留；该账号自己的登录、备份和其他未链接的文件会被删除。对于 Codex，这包括该账号的记忆。
- 如果 PlanSwap 因账号正在使用而拒绝删除，请关闭它列出的会话或进程后重试。

PlanSwap 启动或刷新时，会把在你的主目录中找到的、名称有效的账号目录自动加入列表。

## 使用工具

账号列表下方的 **工具** 提供该标签页专属的操作：

| 工具 | 作用 |
| --- | --- |
| `CLAUDE.md` 或 `AGENTS.md` | 打开当前 Claude 账号或生效 Codex 账号的规则文件。文件不存在时，会先询问是否创建。 |
| 插件设置 | 打开官方 Claude Code 或 Codex 插件的设置。 |
| 重新链接 | 修复该标签页中链接账号的链接（Claude：还会更新它们的 MCP 服务器）。仅在存在链接账号时显示。 |
| 更新 CLI | 打开一个终端，运行该产品的更新命令。在终端中关注进度和提示；如果你用其他方式安装了 CLI，可能需要用同样的方式更新。 |

页脚提供：

| 按钮 | 作用 |
| --- | --- |
| 显示 CLI 与插件版本 | 显示或隐藏一张卡片，列出两个 CLI 和两个官方插件。未安装的项显示 **未找到**。 |
| 使用说明 | 在 GitHub 上打开本说明。 |
| 重新加载窗口 | 立即重新加载当前窗口，不会询问。 |
| 重启扩展宿主 | 立即重启扩展宿主，不会询问。 |
| Star | 打开 PlanSwap 的 GitHub 仓库。 |

要获取排障报告，请在命令面板中运行 **PlanSwap: 预览诊断报告**（PlanSwap: Preview Diagnostics Report）。阅读后，如需分享，选择 **复制报告**。报告用编号指代账号，不包含账号名、邮箱、目录和凭据。不会自动上传任何内容。

## 更改语言和显示设置

点击面板标题栏中的设置图标，或运行 **PlanSwap: 打开 PlanSwap 设置**（PlanSwap: Open PlanSwap Settings）。更改立即生效：

| 设置 | 默认值 | 用途 |
| --- | --- | --- |
| `planswap.language` | `auto` | 跟随编辑器，或选择 `en`、`zh-cn`、`zh-tw`、`es` 或 `ja`。 |

## 排查常见问题

| 现象 | 检查什么 |
| --- | --- |
| Claude 仍在使用之前的账号 | 重新加载窗口，让已打开的 Claude 面板改用新账号。检查是否有 PlanSwap 警告提示环境凭据或提供方设置覆盖了该账号的登录。 |
| Codex 显示有待生效的选择 | 按你的环境完成重启。重新加载窗口不能代替重启编辑器或 WSL 服务端。 |
| 无法启用 Codex 切换 | 查看列出的 shell 或 `CODEX_HOME` 冲突。在 Windows 上，检查 Codex 是否设置为在 WSL 中运行。 |
| 某个账号仍显示 **未登录** | 用该行的 **登录** 按钮登录，然后刷新。仅保存在操作系统密钥环中的 Codex 登录无法检测到，因为 PlanSwap 查找的是该账号的 `auth.json`。 |
| 两个账号触发重复登录警告 | 两者登录的是同一账号和工作区，因此在它们之间切换不会得到独立的额度。请在其中一个里登录你想要的身份。 |
| 没有用量条，或查询失败 | 检查该账号是否以订阅（Claude）或 ChatGPT（Codex）方式登录，以及是否已安装 `claude` 命令（Claude）。手动刷新并阅读失败消息；如果提示冷却中，请稍等再重试。如果提示未能及时响应，可调大 `planswap.claude.usageTimeoutSeconds` 或 `planswap.codex.usageTimeoutSeconds`。 |
| 设置或历史没有按预期共享 | 检查链接标记，以及转换或重新链接的结果。有些文件会保持独立或需要手动合并；在 Windows 上，检查是否能创建文件链接。 |
| 列表看起来过时了 | 点击面板标题栏中的刷新按钮。在其他窗口中所做的更改要刷新后才会显示。 |

关于登录被覆盖、会话共享的限制和 Windows 注意事项，请参阅[已知限制](../README.md#known-limitations)和[原生 Windows](../README.md#native-windows)。PlanSwap 在本地存储哪些内容、以及查询用量时如何使用官方客户端，请参阅[隐私](../README.md#privacy)。

## 停用切换或卸载

1. 把 Claude 切换回 `default` 并重新加载窗口。
2. 如果已启用 Codex 切换，运行 **停用 Codex 账号切换**（Disable Codex Account Switching，位于命令面板的 **Codex 账号** 分类下）并确认。这会移除 PlanSwap 的 shell 代码块（在 Windows 上则是它设置的用户级 `CODEX_HOME`），并清除选择。已打开的窗口在按[选择账号并使其生效](#选择账号并使其生效)中所述重启之前，仍使用旧账号。
3. 如有需要，在扩展视图中卸载 PlanSwap。

账号目录会被保留。如果还想清除 PlanSwap 保存的账号列表、显示名和用量记录，请参阅[卸载说明](../README.md#uninstall)。这不会改动各账号自己的文件。
